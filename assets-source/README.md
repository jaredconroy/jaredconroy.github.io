# Add portfolio content here

Drop original files into the matching folder and add any notes to its `NOTES.md`. These folders stay local and are not copied into the website build. Raw files are ignored by Git; the Markdown notes are not. Keep your own backup of originals.

| Folder | What to add first |
| --- | --- |
| `foul-balls/` | Pitch-bible cover, PDF, character art, a short logline and credits |
| `the-sleds/` | Performance photo or montage, album cover, music-video files/links |
| `afroman/` | Optional new gameplay screenshots, development notes and credits |
| `design/` | Logo and branding selections, names and short captions |
| `illustration/` | Illustrations and character sheets, names and short captions |
| `audio/` | Finished tracks, artwork, titles, artist/project names and track order preferences |
| `about/` | Headshot, bio, résumé PDF, credits, public email and launched accounts |

JPEG/PNG/WebP, SVG, PDF, MP4 and MP3 are useful delivery formats. Illustrator/PSD files and WAV masters can stay here as originals. A short text file or each folder's `NOTES.md` can hold video URLs, captions, credits and ordering. Supply alt descriptions when the artwork's subject needs explanation.

After adding files, tell me which folder is ready. I will optimize the assets and wire them into the pages. Copying files here does not automatically display them on the site.

See `../CONTENT_GUIDE.md` for the public export locations and code connections.
