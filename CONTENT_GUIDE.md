# Populating the portfolio

## Easiest handoff

Place your originals in `assets-source/<project>/` and add filenames, captions, credits, preferred ordering and links to its `NOTES.md`. Tell me when that folder is ready. Keep originals here instead of `public/`: every file under `public/` is included in a deployed site, even if no page links to it.

Illustration and Foul Balls image exports are automatically imported during local development and builds (see below). Other folders remain an organized handoff for integration. Raw masters are never deployed directly.

## Export guidance

- Hero imagery: around 1600–2000px wide; preserve portrait artwork inside the landscape viewport rather than cropping it. SVG is useful for logos.
- Video previews: short, silent H.264 MP4 with a poster image. Full music videos can use files or supplied live links; don't put a full-length video in the landing carousel.
- Gallery images: JPEG/WebP for photographs, PNG/WebP for illustrations that need transparency, SVG for vector logos. Keep high-resolution/editable masters in `assets-source/`.
- Player audio: MP3 is a practical streaming copy; WAV masters can remain local. For every track provide title, artist, parent project, optional year/category, artwork and any specific destination within the project.
- Resume/pitch bible: PDF. Add only the personal/contact information you want public.

All deployed asset URLs must use `import.meta.env.BASE_URL` (as `afroman.ts` and `tracks.ts` do) so repository-subpath GitHub Pages hosting works. Don't edit `dist/`; it is regenerated by the build.

## Illustration and shared Foul Balls artwork

Put finished PNG, JPEG, WebP, AVIF, or SVG image exports anywhere under `assets-source/illustration/` or `assets-source/foul-balls/`. The local Vite server watches these folders; restarting development or running a build also imports them. New Foul Balls images automatically appear in Illustration's Foul Balls collection and the Foul Balls page's additional artwork gallery. The existing poster remains shared without being duplicated on the Foul Balls page. AI, PDF, audio, and other masters are not imported as gallery images.

Use `src/content/illustration-details.json` to set titles, alt text, captions/credits, ordering, and background color. Keys are paths relative to `assets-source/`, such as `foul-balls/character-sheet.png`. New files get readable filename-based titles until you supply copy. Transparent Foul Balls artwork defaults to Cougars tan; set an appropriate per-image `background` for other artwork. Transparent design logos retain their individual brand colors in the homepage preview and comparison lab.

Run `pnpm assets:illustrations` to export manually. Local importing requires Python 3 and Pillow. Exports are capped at 2200px with 760px thumbnails; the originals remain intact. Commit the optimized `public/media/` files and generated `src/content/illustration-assets.json` with the website. A clean GitHub checkout without the ignored masters uses those committed files and does not require Python or Pillow. Adding local artwork does not publish it until the normal deployment.

Compare six possible homepage compositions at `/labs/previews/index.html`. The shortlist controls save preferences only in that browser; they do not alter the homepage. The lab uses the same Illustration manifest and brand-backed design assets as the site.
